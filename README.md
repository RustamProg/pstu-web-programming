# Интернет-магазин созданных в ходе лабораторных работ по предмету "Веб-программирование"

Выполнил: Габдулбаров Рустам Зиннурович
Группа: ИСТ-23-1бзу

Создан проект ASP.NET Core Web App MVC.
В нем одновременно сделаны MVC страницы + WebApi эндпоинты для React-приложения. Сделано так, чтобы можно было переиспользовать логику внутри. Также можно в одном браузере открыть обе страницы, данные между ними синхронизируются.

- В папке PstuEshopWebApp - ASP.NET Core Web App MVC
- В папке pstu-eshop-react - React-приложение
